# Phase 5 Prompt — SEO, Performance, Accessibility, Security, Preview

Resume only after P2–P4 gates pass. Implement the security, privacy, SEO, performance, accessibility, motion and release documents fully.

Run a current threat model and ASVS Level 2 applicability matrix; authorization/RLS/API/webhook/replay/rate/injection/secret/dependency/log/privacy/backup/restore/deletion tests. Validate indexable rendered content, metadata, canonical, sitemap, robots, redirects, 404, structured data, internal links and private noindex. Test mobile Core Web Vitals budgets, bundles, images, fonts, third parties, keyboard, screen-reader sample, reflow and reduced motion.

Create a preview only if allowed. Produce one production-approval packet with exact commit/URL, gate results, evidence, limitations, provider states, recurring costs, migration impact, rollback and monitoring. Stop at G5. Do not deploy production from a preview approval.

Update all durable state and handoff files even if the release gate fails. A failed check must remain visible with one exact repair action.
