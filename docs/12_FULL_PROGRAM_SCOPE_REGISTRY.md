## Social setup is not optional shorthand

W03–W07 must include all of the following:

1. audit actual live state before drafting;
2. current platform rules and eligibility;
3. founder-versus-IronWake platform role;
4. handle/name/bio/About/category/avatar/cover/CTA/link/contact specification;
5. logo-led agency identity; a founder portrait is optional and must never be invented;
6. owner, recovery owner, MFA, admins, permissions, disconnect, and incident notes;
7. human-controlled login, account creation/edit, CAPTCHA, terms, identity/KYC, and publication;
8. logged-out desktop/mobile verification of profile, links, contact route, and visual crops;
9. nine source assets: Start Here; Proof Index; How IronWake Works; RapidPulse; DentaCare; Atelier; Five Inquiry Leaks; Demo vs Pilot vs Verified Live; Business Leak Audit;
10. pin Start Here, Proof Index, and How IronWake Works on the primary platform where supported;
11. LinkedIn reasoning, Instagram carousel, short-form demo, GitHub technical proof, and website case-study adaptations where appropriate;
12. truthful proof labels and real/approved media only;
13. reply, moderation, consent, opt-out, escalation, cadence, analytics, and measurement;
14. no fake followers, engagement, verification, clients, outcomes, integrations, testimonials, partnerships, or badges;
15. no unsolicited automated DMs, connections, follows, comments, or engagement;
16. verified URLs only on the website;
17. CRM tracking of platform, account, campaign/content ID, first/last touch, consent, owner, next action, and real outcome;
18. success measured by qualified replies, inquiries, meetings, proposals, and sales—not likes alone.

## Execution ownership

| Work | OpenCode C1/C2/C3 | OpenCode M1/M2 | Human/adult/legal owner |
|---|---|---|---|
| Research, eligibility, architecture, pricing, claims, threat model, task design | Owns | Must follow | Approves material facts/choices |
| Profile copy, content strategy, proof classification | Owns and audits | Produces approved variants/assets | Approves |
| Account login/create/edit, MFA, CAPTCHA, terms, publication, external messages | Prepares/verifies only | Never performs unless explicitly supported and approved; still no identity bypass | Owns |
| Website, CRM, content asset production, tracking, tests | Specifies/audits | Implements | Supplies real data and approvals |
| Proposals/contracts/invoices/payment rules | Designs controlled templates; audits | Implements workflow | Adult/legal owner/professional approves regulated/legal/payment decisions |
| Final production release | Audits and controls exact commit | Remediates only | Explicitly approves external release |

- status vocabulary from the continuity protocol;
- exact evidence;
- live/tested-demo/pending-provider/deferred classification;
- responsible owner;
- unresolved blocker;
- recurring cost;
- next operational action.
