## 4. Truthful limits

- No process can guarantee that every competitor will be impressed.
- No ethical pricing system can guarantee that customers never compare prices.
- No website can guarantee Google's highest ranking.
- No team can honestly promise zero future bugs or “military-grade” security without a defined audited standard.

v5 converts those goals into measurable requirements plus independent OpenCode role separation, sealed queues, complete social execution, W00–W22 evidence coverage, monitoring, and honest residual risks.

## 5. Exact first use

1. Put this unzipped v5 folder in the actual Git-backed IronWake project root.
2. Put the unzipped Stitch export, Agency/Voice/WhatsApp kits, branding/profile files, build kit, and optional skills in separate folders.
3. Open OpenCode in that root.
4. Run `/ironwake-start`.
5. Let OpenCode C1 follow the locked gates, create the complete W00–W22 plan, and seal the M1 queue.
6. Provide/approve the consolidated missing-data and decision packet.
7. Run M1 only when `required_role: M1`.

If a limit hits, open the same repository in another OpenCode session and run `/ironwake-start`.
