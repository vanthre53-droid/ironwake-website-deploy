## Severity rubric

- **P0** — page produces a horizontal scrollbar, content is clipped off-viewport, an interactive element cannot be reached, or the page returns a non-2xx. Ship-blocker.
- **P1** — visible degradation at a primary mobile viewport (≤430 px). The page is still usable but the visual is unprofessional.
- **P2** — cosmetic, content readable, narrow text-wrap or near-touching cards. Not a launch blocker.

## Defect kind legend

- `horizontal-scroll` (P0) — `documentElement.scrollWidth > documentElement.clientWidth + 1`.
- `body-overflow` (P0) — `body.scrollWidth > clientWidth + 1`.
- `http-status` (P0) — non-200 response from production server.
- `load-error` (P0) — Playwright failed to reach/load the page.
- `cta-clip` (P0) — visible-text node of a CTA extends past the viewport edge.
- `form-overflow` (P0) — form input/select/textarea overflows the viewport.
- `element-overflow` (P1/P2) — interactive element (link/button/nav/etc) overflows viewport.
- `widget-collision` (P1) — two floating widgets (chat / WhatsApp / back-to-top / etc) overlap.
- `text-wrapping` (P1/P2) — a ≥2-line paragraph wraps to <3 words/line (cramped).
- `cards-touching` (P2) — grid neighbour cards touch without a gap (heuristic-class false-positive risk; treat as advisory only).

## Top action items (for the fix pass)

1. **Audit `/pricing` mobile overflow (P0, ship-blocker).** Inspect absolute-positioned children of the offer-matrix table; the 2 px extension is consistent across 360/390/430 (always vw + 2), strongly suggesting a single absolutely positioned indicator (likely a "popular" / "recommended" badge) anchored to a wider container, or a 1 px CSS border / scrollbar-gutter artifact on a child. Recommended fix path: locate the child, constrain to `max-width: calc(100vw - var(--gutter))` or `overflow-x: hidden` on the responsible wrapper.
2. **Tighten `/systems` 360 px and `/` 360 px copy density (P1).** Reduce tag-list/font-size inside system cards on the narrowest breakpoint, or single-column at 360.

## Methodology notes

- Each `(page, viewport)` pair is run with a fresh browser context (no shared cookies / cache / scroll position).
- `domcontentloaded` + 800 ms wait for hydration before sampling DOM.
- Per-element overflow measurement threshold: 1.5 px (sub-pixel quantisation noise allowed; without it, every modern page reports a "clip" because of fractional rendering).
- Form-field overflow filter: include only fields whose right edge is past viewport AND whose left edge is past 0 (hidden/inert widgets excluded).
- Card-tagging noise: the `cards-touching` heuristic uses any element whose className matches `/card|plan|tier|pricing/i`, which will also catch inner content cards. Treat all 9 occurrences as P2 advisory and visually verify before fixing.
- All measurements live in `/tmp/qa/qa-debug.json` and `/tmp/qa/qa-recheck.json` for replay.
