# 02A — PHASE 1.5: PORTFOLIO TRUTH AND PROOF GATE
Role: C1. Starts after G1. Must pass before S1.

For every portfolio item, classify honestly:
  REAL CLIENT ENGAGEMENT | SELF-BUILT DEMONSTRATION | CONCEPT | RETIRED

Produce:
- reports/PORTFOLIO_PROOF_GATE.md — the classification table with evidence per row
- reports/CLAIM_LEDGER.md — every claim that will appear publicly + its proof
- reports/ASSET_LEDGER.md — updated ownership/licensing
- reports/evidence/PORTFOLIO_PROVIDER_PROOF.md — reproducible proof for anything claimed live

Hard rule: a demonstration is labelled DEMONSTRATION on the public site. It is never
implied to be a client engagement. No exceptions, no soft wording.
